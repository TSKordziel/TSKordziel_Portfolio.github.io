Project Card 1 — Codenames Helper (Rust GUI)

Stack: Rust, Iced (GUI), rand, pattern matching, state management

What it is:

A desktop GUI tool for running Codenames word-game sessions locally with adaptive layout, word shuffling, and role tracking. If you are not familiar with the game see the rules Here

Highlights:

  • Built a full GUI in Rust using Iced, including custom button styles and responsive font scaling.
  • Implemented a message-driven state system (update/view pattern) to manage tile selection, role assignment, and game resets.
  • Used compile-time embedded word lists via include_str!() for zero external dependencies and fast startup.
  • Designed a 5×5 grid layout with dynamic resizing and contrast-aware color changes based on enum state (Choice::Red, Blue, Neutral, Death).

Project Card 2 — Sudoku Solver — Rust + Graph Theory

Stack: Rust · Petgraph · Constraint Propagation · Backtracking · MRV Heuristic

What it is:

A fast, from-scratch Sudoku solver built in Rust using a graph-based constraint system. Each cell is a node in a constraint graph, and the solver uses hanging singles, candidate buckets, and an MRV-guided backtracking search to solve even expert puzzles efficiently.

Highlights:

  • Rust Implementation: Strong ownership discipline, zero-cost abstractions, and efficient cloning strategies for branching search.
  • Constraint Graph: 81 nodes, edges define Sudoku legality constraints. Fast neighbor propagation using Petgraph. Each assignment invalidates incompatible neighbors and updates bucket counts.
  • Inference Engine: Implements hanging single detection (deterministic propagation). Automatically narrows constraints before any backtracking begins.
  • Backtracking Solver: MRV heuristic selects the most constrained cell. Recursive search branches over remaining candidates. Propagates implications at each step to aggressively prune invalid branches.
  • Result: Solves medium → expert puzzles extremely quickly, with clean, readable Rust code and a mathematically rigorous architecture.

Repository: Here

Status: Complete / actively refined

Why it matters:

This project demonstrates algorithmic engineering, graph modeling, and systems-level problem-solving in Rust—far beyond typical CRUD/app-dev work. This project wasn’t about solving Sudoku; it was about proving that I can architect and implement a complex state machine with real-time constraint propagation using clean Rust. It was also a testbed for techniques I’m applying to larger projects, including graph-driven world generation and local-first personal knowledge management systems.
