Project #1

My Codenames Helper App

This is an app that I decided to write 100% in Rust from the ground up. It uses the Iced GUI framwork for the UI and it utalizes addaptive text for automated font scaling. The word list is baked into the final executable binarry allowing for a no-install/zero-config experiance once compiled.

The idea beheind this app was to make it easir to set up and play the the board game Codenames. You can find a description of how it is played here.

The "Word Cards" within the app are randomly filled with words and the clue givers can esally change the bacground of each card acording to what team the word belongs to.
