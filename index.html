Project Card 1 — Codenames Helper (Rust GUI)

My Codenames Helper App

Title: Codenames Helper — Rust Desktop App

Stack: Rust, Iced (GUI), rand, pattern matching, state management

What it is:

A desktop GUI tool for running Codenames word-game sessions locally with adaptive layout, word shuffling, and role tracking. If you are not familiar with the game see the rules Here

Highlights:

  • Built a full GUI in Rust using Iced, including custom button styles and responsive font scaling.
  • Implemented a message-driven state system (update/view pattern) to manage tile selection, role assignment, and game resets.
  • Used compile-time embedded word lists via include_str!() for zero external dependencies and fast startup.
  • Designed a 5×5 grid layout with dynamic resizing and contrast-aware color changes based on enum state (Choice::Red, Blue, Neutral, Death).
  • Abstracted UI behavior into component-style helpers (button_helper, make_container) for reusable code and consistent styling.
